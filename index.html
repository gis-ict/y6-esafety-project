E-safety rules and question ideas

ກົດຄວາມປອດໄພອອນລາຍ ແລະ ຕົວຢ່າງຄຳຖາມ

Pick ONE rule for your game. Use these questions, or change them to make your own.

The 12 e-safety rules

  1. Think before you post. Online can stay online.
  2. Deleted is not gone. Friends can screenshot it.
  3. Keep info private. Address, school, phone, birthday.
  4. Ask before you post a friend's photo.
  5. Use two locks (MFA). A code on a grown-up's phone.
  6. Know, have, are. Password, phone code, fingerprint.
  7. Long and random wins. pizza-moon-rocket.
  8. Never share passwords or login codes.
  9. Free prize? Stop! Close pop-ups that want passwords.
  10. Don't click strange links.
  11. Strangers stay strangers in game chat.
  12. Tell a trusted adult if something feels wrong.

Make your own question

1. Pick a rule. 2. Think of a real situation. 3. Ask: Should you...? (y or n) or Which is safer? a = ... b = ... 4. Write the right answer and a short tip.

🐞 The score starts at the old number

Add set score to 0 under the green flag.

🐞 I typed the right answer but it says wrong

Check the spelling in the if answer = block. "8" and "eight" are different. Remove any extra spaces.

🐞 The game never ends

Add a win message after the last question and an if lives = 0 check after each question.

🐞 Lives go below 0

The if lives = 0 check is missing or in the wrong place. Put it after each question.

🐞 It takes longer than 2 minutes

Make the say for times shorter, or remove one question.

🐞 Year 3 did not understand a question
